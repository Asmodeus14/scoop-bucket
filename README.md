# Scoop bucket for ChronoStack

[ChronoStack](https://github.com/Asmodeus14/ChronoStack): Stripe Test Clocks for your Docker Compose stack.

```powershell
scoop bucket add chronostack https://github.com/Asmodeus14/scoop-bucket
scoop install chronostack/chronostack
```

Upgrade with `scoop update chronostack`. ChronoStack needs Docker Desktop with Compose v2.

The manifest installs the prebuilt Windows binary from the [ChronoStack releases](https://github.com/Asmodeus14/ChronoStack/releases), checked against its SHA-256 sum. It is updated when a ChronoStack release is published. ChronoStack is in alpha.
